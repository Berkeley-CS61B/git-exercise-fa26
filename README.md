# git-exercise-fa26

Welcome to Lab 4's Git Exercise, where you'll be exploring this repository.

This short exercise is designed to give you practice with some core git commands
and concepts.

There are three passwords hidden in here:

- One was deleted by a commit that should not have deleted it. You will need to
  undo that commit without throwing away the work that came after it.
- One is on another branch.
- One is not in this repository at all.

Good luck!
